How a tip gets made

The method

The same checks run on every bet. A tip that fails one doesn't go out.

Matchup

Start from the defences that give up the most, or the least, to each position, confirmed on the stat the bet pays on.

Real line

Pull the bookmaker's actual main and alternate lines. No guessed prices.

Research

Minutes, shots and targets, injuries and news, coverage and pace, and how the same role has done against this defence.

Stake

The depth of the research sets the units. Every result goes in the ledger, win or lose.
