# Wager AU

The Wager AU website: NFL and NBA player-prop tips, with every result logged. Static HTML, hosted free on GitHub Pages.

- `data/tips.json`: the current tips.
- `data/results.json`: every official bet and its result, exported from the model's UNIT TALLY sheets.
- `tools/build.py`: rebuilds the pages from the data. Run `python3 tools/build.py`, then commit and push.
- `assets/style.css`: the site's styles.
