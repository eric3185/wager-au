The model

The Wager AU model

A matchup model for NFL and NBA player props, run before every betting day.

Ratings

Every defence, every position

All 32 NFL defences rated against QBs, RBs, WRs and TEs each week, and every NBA team against guards, forwards and centres.

Usage

Real roles

Target, carry and minute shares refreshed before every betting day from the latest box scores and news.

Pricing

Every line priced

Sportsbet main and alternate lines run through the model to get a projection and a win probability for each bet.

Gates

Research checks

A bet goes out only when the matchup, the role against this defence, the game script and the news all line up.

Step by step

  • Rate the matchups. Each defence is ranked against each position on the stat the bet pays on: yards, receptions, points, rebounds, assists, threes.
  • Set the roles. Each player's share of targets, carries or minutes comes from the latest games and team news.
  • Price the lines. The model projects each player's number and turns it into a win probability for the exact line and price on offer.
  • Run the checks. The same role has to clear the line against this defence, and the coverage, pace and expected game script have to fit.
  • Stake by confidence. The more the research agrees, the bigger the stake. Multis use lower alternate lines priced around 1.70 to 2.20.
